# Копилка

Одностраничный сайт-копилка без зависимостей: вписываете цель, добавляете или убавляете суммы, сайт сам показывает, сколько накоплено и сколько осталось. Его можно поставить на главный экран телефона как приложение.

## Что умеет

- Три темы (выбор в меню, запоминается):
  - «Ночное небо» — кольцо прогресса, цель внутри кольца (основная);
  - «Банка мечты» — банка наполняется, накопленная сумма в заполненной части, остаток в пустой;
  - «Рассвет» — солнце поднимается над горизонтом по мере накоплений.
- Несколько копилок: «Новая копилка» в меню, переключение вкладками под шапкой (появляются, когда копилок больше одной). У каждой своё название, цель, срок, валюта и история; тема общая.
- Срок цели (необязательно): сайт показывает, сколько дней осталось и сколько нужно откладывать в день, неделю и месяц.
- Меню (кнопка справа вверху): копилки, название, цель, срок, валюта (любой свой знак или название), выбор темы, калькулятор (результат можно перенести в поле суммы), кнопка «Добавить на главный экран», копия данных, обнуление накоплений.
- Сумму можно писать как `500`, `+500` или `−200`: `Enter` добавит или уберёт её. Есть кнопки «Добавить» и «Убавить».
- История операций с возможностью удалить запись.
- Поздравления на 25 / 50 / 75 % и конфетти при достижении цели.
- Вёрстка под телефон, на широком экране страница раскладывается в две колонки.

## Установка на главный экран

Сайт нужно открыть по адресу `https://…` (например, через GitHub Pages).

- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран “Домой”».

Название приложения — «Копилка». Иконка зависит от темы, которая включена в момент установки. Чтобы сменить иконку, выберите другую тему, удалите значок и установите заново.

После первого открытия копилка работает и без интернета.

## Где хранятся данные

Всё хранится в браузере: копилки (цель, срок, валюта, история) и тема. Основное место — `localStorage` (ключ `onadream:v1`), вторая копия — в IndexedDB; если iPhone очистит `localStorage`, данные вернутся из копии. Сайт также просит у браузера постоянное хранилище. У каждого посетителя свои данные.

Установленное на iPhone приложение хранит данные отдельно от вкладки Safari и от других устройств. Чтобы перенести данные: в меню → «Копия данных» → «Скопировать», в другом месте → «Вставить» → «Восстановить». Код начинается с `KOP1:`.

## Файлы

- `index.html` — разметка и скрипт, который подставляет иконку и манифест под тему
- `style.css` — темы, вёрстка, анимации
- `app.js` — логика
- `manifest.webmanifest` — манифест приложения (по умолчанию тема «Ночное небо», при смене темы подменяется)
- `sw.js` — service worker для работы без интернета
- `icons/` — иконки трёх тем (SVG-исходники и PNG 180, 192, 512)
