# On a dream — копилка

Одностраничный сайт-копилка без зависимостей: вписываете цель, добавляете или убавляете суммы, сайт сам показывает, сколько накоплено и сколько осталось.

## Что умеет

- Две темы: «Ночное небо» (кольцо прогресса, цель внутри кольца, основная) и «Банка мечты» (банка наполняется, накопленная сумма написана в заполненной части, остаток — в пустой). Переключатель темы находится в меню.
- Меню (кнопка справа вверху): цель, валюта (любой свой знак или название), смена темы, обнуление накоплений.
- Сумму можно писать как `500`, `+500` или `−200`: `Enter` добавит или уберёт её. Есть кнопки «Добавить» и «Убавить».
- История операций с возможностью удалить запись.
- Поздравления на 25 / 50 / 75 % и конфетти при достижении цели.
- Вёрстка под телефон, на широком экране страница раскладывается в две колонки.

## Где хранятся данные

Всё хранится в `localStorage` браузера (ключ `onadream:v1`): цель, валюта, тема и история. У каждого посетителя свои данные, между устройствами и браузерами они не синхронизируются.

## Запуск

Откройте `index.html` в браузере или выложите папку на любой статический хостинг, например GitHub Pages.

## Файлы

- `index.html` — разметка
- `style.css` — темы, вёрстка, анимации
- `app.js` — логика
